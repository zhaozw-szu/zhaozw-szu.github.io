1.pix2tex

lukas-blecher/LaTeX-OCR: pix2tex: Using a ViT to convert images of equations into LaTeX code. (github.com)

以下是PC安装的流程

首先安装pix2tex：

pip install "pix2tex[gui]"

然后再安装了pix2tex的环境下的终端下输入：

latexocr

最后编写一个’run_latexocr.bat‘文件，内容为：

@echo off
:: 打开 Anaconda Prompt (miniconda3)，激活环境并运行 latexocr

:: 设置 Anaconda 安装目录
set ANACONDA_PATH=C:\Users\zhaozw\miniconda3

:: 打开 Anaconda Prompt 并激活环境
%windir%\System32\cmd.exe /K "%ANACONDA_PATH%\Scripts\activate.bat %ANACONDA_PATH% && conda activate pythonStudy && latexocr"

之后每次使用，都可以之间点击’run_latexocr.bat‘文件来打开公式识别的界面
